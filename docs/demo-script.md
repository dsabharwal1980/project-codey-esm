# Demo script (≈ 12 minutes) – Project Codey ESM

Setup: Slack (Agentforce ESM_Codey) or Claude Desktop with the esm-codey connector; the Codey Setup app open in a second tab.

| # | Say | Show |
|---|---|---|
| 1 | "What can you do for Enterprise Sales Management?" | the 8 skills in one sentence |
| 2 | "Check if my setup is correct." | Health check report: OK / Warning / Needs Fix, reasons, help links |
| 3 | Click **Fix it** on "Core logs off" → "approve" | Approval card Before true → After false; done + change log id; re-check OK |
| 4 | "Undo that change." → "approve" | value restored (undo) |
| 5 | "Give Jane Doe the Sales rep permission sets." | missing sets → approve → assigned → re-check |
| 6 | "Explain our price plan." then "Price 1 × <offer> for <account> without saving." | ordered steps; price breakdown, nothing saved (quote count unchanged) |
| 7 | "Explain Quote Member vs quote line item using quote <name>." | short answer with real counts and help link |
| 8 | "Check addresses on quote <name>." (or attach a CSV) | preview → approve → Progress tracker → results file on the quote |
| 9 | "Run the admin jobs." → "approve" | Progress tracker, manual steps flagged |
| 10 | "What will the next upgrade affect?" | Upgrade impact report, High first |
| 11 | Codey Setup → Activity | every read, preview and commit in the Change Log |
| 12 | Open the ESM Coworker on a quote: "Check my ESM settings" | same skills inside the Coworker |
