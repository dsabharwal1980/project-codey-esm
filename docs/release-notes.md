# Release notes – Project Codey: Enterprise Sales Management Ease of Build (PRD ESM-268)

**What's new.** Ask an AI agent – in Slack, Microsoft Teams, Claude, ChatGPT, Agentforce Vibes, Cursor, Agentforce or the ESM
Coworker – to do the standard ESM build work for you. The agent looks at your org, follows a written skill, shows a preview,
waits for your approval and confirms the result.

| You can now… | Ask for example |
|---|---|
| Install and set up ESM on a sandbox (prerequisites, packs, permissions, Console, Google Maps key, admin jobs, a priced test quote) | "Install Enterprise Sales Management on my sandbox." |
| Check quoting, add-assets-to-quote, performance, Console, permission and admin-job settings | "Check if my setup is correct." |
| Give each user type the right permission sets | "Give the new sales team access." |
| Run the admin jobs in the documented order and follow their progress | "Run the admin jobs." |
| See which customized screens a release affects | "What will the next upgrade affect?" |
| Get plain answers about Enterprise Quotes, Quote Members and Enterprise Orders with your own data | "Explain a Quote Member vs a quote line item." |
| Understand and change price plans, tested on a sample quote | "Add a regional surcharge step to our price plan." |
| Load thousands of quote members and check addresses and serviceability | "Load these 4,000 sites onto this quote and check them." |
| See which promotions and discounts applied, and why | "Which promotions applied on quote Q-123?" |
| Set up linear relationships, Quote Member Binding, context rules and Enrich Quote options | "Only allow this product at sites in the North region." |

**Built in:** four experience screens (Approval, Health check report, Progress tracker, Upgrade impact report) that look the same
everywhere; nothing is saved without your approval; sandbox by default; production changes need extra confirmation; secrets are
entered on a secure page, never in chat; every action is logged in the Codey Change Log.

**Licensing:** existing Communications Cloud and Enterprise Sales Management licences. **Org preference:** none.
**Permissions:** assign *ESM Codey User* (and *ESM Codey Admin* for admins). The agent works with the permissions of the person who asks.
**Upgrade:** skills and knowledge packs are refreshed every release.
