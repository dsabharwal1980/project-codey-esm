# Set up Project Codey for Enterprise Sales Management

1. **Install** – your admin deploys Project Codey (see the Cross-Org Deployment & Usage Guide) and assigns you *ESM Codey User*.
2. **Connect your AI tool** – Agentforce and the ESM Coworker work right away. For Slack, Teams, Claude, ChatGPT, Vibes or Cursor,
   your admin gives you the Codey connection; you log in with your own Salesforce user the first time.
3. **Ask** – write what you need in plain words. Codey shows a preview and waits for your *Approve*.

## Sample requests
- Install Enterprise Sales Management on my new sandbox.
- Check if my setup is correct. · Check only the performance settings. · Why does adding assets to a quote fail?
- Give the new sales team access (profile "Sales User"). · Which permission sets does a pricing admin need?
- Run the admin jobs. · How far are the admin jobs? · Resume the failed admin job.
- What will release 268 affect? · Suggest a merged version of our cart configurator card for review.
- Explain the difference between a Quote Member and a quote line item (use quote "Acme Retail 60 sites").
- How do Enterprise Quotes, Quote Members and Enterprise Orders fit together?
- Explain our price plan. · Add a regional surcharge step after Apply Offer Adjustments. · Price 2 × "BT Net 1G" for Acme without saving.
- Which promotions and discounts applied on quote Q-00123, and why? · Promotion in the cart vs discount on the quote?
- Set up an upgrade path from Fibre 500 to Fibre 1G. · Bind the site's access technology to the product attribute.
- Only allow Fibre 1G at sites in the North region. · Which Enrich Quote options do we offer?
- Load these 4,000 sites onto this quote and check them (attach the spreadsheet). · Re-check serviceability for all sites.

## Good to know
- **Approve / Reject** – nothing changes until you approve the preview card.
- **Google Maps key** – App Launcher → *Codey Setup* → *Google Maps key*. Never paste keys in chat.
- **What did Codey do?** – App Launcher → *Codey Setup* → *Activity* (Change Log and Jobs).
- **Undo** – "Undo change CL-000123" (preview first).
