# Agentforce – the ESM_Codey agent (Agent Script)

`force-app/main/default/aiAuthoringBundles/ESM_Codey/ESM_Codey.agent` is generated by `scripts/build-agents.py` from the same tool
spec as the MCP server: a router and 8 subagents (one per skill) calling the Codey Apex actions (`apex://Codey*Tool`).

```bash
sf project deploy start -d force-app/main/default/aiAuthoringBundles/ESM_Codey -o <org>      # deploy the draft bundle
sf agent validate authoring-bundle --api-name ESM_Codey -o <org> --json
sf agent publish authoring-bundle --api-name ESM_Codey -o <org> --json
sf agent activate --api-name ESM_Codey -o <org>
sf agent preview start --api-name ESM_Codey -o <org> --json   # then: sf agent preview send --session-id <id> -u "Check if my setup is correct"
```
It is an Employee agent: it runs as the signed-in user, so users need `ESM_Codey_User` (plus their normal ESM permissions).
Add it to the Lightning utility bar / Agentforce panel, Slack and mobile from Setup → Agentforce Agents → ESM_Codey.
