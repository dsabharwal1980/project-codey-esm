# ESM Coworker – add the Codey build skills

The ESM Coworker (ESM New Experience) gets the same skills, tools and playbook through one extra subagent `build`
(`codey_build_subagent.agent.txt`, generated by `scripts/build-agents.py`).

```bash
sf project retrieve start -m "AiAuthoringBundle:ESM_Coworker" -o <org>                     # the DRAFT bundle (no version suffix)
python3 scripts/merge-coworker.py force-app/main/default/aiAuthoringBundles/ESM_Coworker/ESM_Coworker.agent
sf project deploy start -d force-app/main/default/aiAuthoringBundles/ESM_Coworker -o <org>
sf agent validate authoring-bundle --api-name ESM_Coworker -o <org> --json
sf agent publish authoring-bundle --api-name ESM_Coworker -o <org> --json                  # new version; the previous one stays for rollback
sf agent activate --api-name ESM_Coworker -o <org>
```
Assign `ESM_Codey_User` to Coworker users (next to `ESM_Coworker_Access`). The merge is idempotent (it skips if `build` exists).
