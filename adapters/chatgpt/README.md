# ChatGPT

**Developer mode / connectors (MCP):** Settings → Connectors → Create → URL = the Hosted MCP URL of `EsmCodeyEaseOfBuild`,
authentication OAuth (the External Client App's client id; callback URL as shown by ChatGPT – add it to the External Client App).

**Custom GPT (alternative):** paste `instructions.md` as the GPT instructions, upload `playbook/PLAYBOOK.md`, `skills/*/SKILL.md` and
`knowledge/*` as Knowledge, and add the MCP connector above as the action source.

Cards: ChatGPT shows text; summarise the `card` (title, badge, rows, buttons as suggested replies) – the instructions say how.
