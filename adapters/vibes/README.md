# Agentforce Vibes (VS Code)

1. Add the MCP servers in `.vscode/mcp.json` (see `mcp.json` here) – the Hosted MCP server and, optionally, codey-knowledge.
2. Copy `vibes/codey-rules.md` into your Vibes rules (e.g. `.a4drules/codey.md`) so the agent follows the playbook.
3. Vibes runs next to the Salesforce CLI, so it can also do the developer-surface steps (packages, configuration packs, merged
   FlexCard versions for review) – still preview → approval → deploy.
