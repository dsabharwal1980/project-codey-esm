**User story:** As a consultant, I want to understand and set up QMB, context rules and Enrich Quote options so the quote fits the customer's process.

**Acceptance criteria (PRD):** Each option is explained. The rule or setting is drafted, previewed, approved, turned on and tested on sample members.

## Flow
`apply_esm_change changeType=contextRule|attributeBinding|enrichQuoteOption → preview_esm_price locations=<members>`

Every change follows the golden rules in PLAYBOOK.md (preview → explicit approval → commit → verify → summary with log id).

2. [ ] Draft context rule → Approval → created (inactive) → second approval turns it on.
3. [ ] Test with 2–3 members in/out of the region.
