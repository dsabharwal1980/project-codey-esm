# US-04 – Admin jobs

| | |
|---|---|
| Priority | Must have |
| Persona | Admin |
| Skill | `fresh-install (admin jobs step)` |
| Cards | Progress tracker |

**User story:** As a admin, I want to run the admin jobs in the right order and tell me when they're done, so products and prices are up to date.

**Acceptance criteria (PRD):** Jobs run in the documented order. Progress is visible. Failures are explained in plain words.

## Flow
`run_esm_admin_jobs mode=preview → approve → mode=commit → track_codey_job`

Every change follows the golden rules in PLAYBOOK.md (preview → explicit approval → commit → verify → summary with log id).

## Test script (done when every line passes)
1. [ ] Ask: "Run the admin jobs".
2. [ ] Preview lists jobs in documented order (auto + manual steps).
3. [ ] Approve → Progress tracker shows step-by-step status.
4. [ ] Simulate/observe a failure → plain message + Resume restarts from the failed step.

## Evidence to record (docs/test-results.md)
Request text · tool calls (inputs/outputs) · card shown · approval given · result · verification · change log / job id.
