# US-01 – Fresh install

| | |
|---|---|
| Priority | Must have |
| Persona | Consultant |
| Skill | `fresh-install` |
| Cards | Approval, Progress tracker, Health check report |

**User story:** As a consultant, I want to install and set up ESM on a new sandbox so I have a working base in hours, not days.

**Acceptance criteria (PRD):** Prerequisites are checked first. Data/Configuration packs, permission sets, Console settings, the Google Maps key (entered securely) and admin jobs are done in the right order. A test Enterprise Quote is created and priced at the end.

## Flow
`check_esm_setup scope=prereq → manage_esm_permissions → apply_esm_change (console) → secure Google Maps form → run_esm_admin_jobs → preview_esm_price (commit = keep test quote) → check_esm_setup`

Every change follows the golden rules in PLAYBOOK.md (preview → explicit approval → commit → verify → summary with log id).

## Test script (done when every line passes)
1. [ ] Ask: "Install Enterprise Sales Management on my sandbox".
2. [ ] Agent runs prerequisites; card shows OK/Needs Fix.
3. [ ] Agent shows install plan (Approval) – approve.
4. [ ] Permission set preview → approve → assigned.
5. [ ] Google Maps key entered on Codey Setup page (never in chat).
6. [ ] Admin jobs Progress tracker reaches Completed.
7. [ ] Test quote priced (total > 0) and kept after approval.
8. [ ] Health check: 0 Needs Fix.

## Evidence to record (docs/test-results.md)
Request text · tool calls (inputs/outputs) · card shown · approval given · result · verification · change log / job id.
