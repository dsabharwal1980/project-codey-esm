# US-03 – Permission sets

| | |
|---|---|
| Priority | Must have |
| Persona | Admin |
| Skill | `permissions` |
| Cards | Approval |

**User story:** As a admin, I want to each user type gets the right permission sets, so users can see and do what they need.

**Acceptance criteria (PRD):** Missing permission sets are shown for each user type, and assigned after approval.

## Flow
`manage_esm_permissions mode=preview → approve → mode=commit → mode=preview (re-check)`

Every change follows the golden rules in PLAYBOOK.md (preview → explicit approval → commit → verify → summary with log id).

## Test script (done when every line passes)
1. [ ] Ask: "Give the new sales team access" and name the users/profile.
2. [ ] Approval card lists missing sets per user.
3. [ ] Approve → assigned.
4. [ ] Re-check shows all users OK.

Request text · tool calls (inputs/outputs) · card shown · approval given · result · verification · change log / job id.
