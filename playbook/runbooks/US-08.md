# US-08 – Address verification and serviceability

| | |
|---|---|
| Priority | Must have |
| Persona | Consultant |
| Skill | `bulk-members` |
| Cards | Approval, Progress tracker |

**User story:** As a consultant, I want to load thousands of quote members from a spreadsheet and check addresses and serviceability.

**Acceptance criteria (PRD):** Data is checked before loading. Checks run in the background with progress. A results file lists each member and the reason for any failure.

## Flow
`check_quote_members_bulk mode=preview → approve → mode=commit → track_codey_job → results file`

Every change follows the golden rules in PLAYBOOK.md (preview → explicit approval → commit → verify → summary with log id).

## Test script (done when every line passes)
1. [ ] Ask: "Load these 4,000 sites onto this quote and check them" with a CSV.
2. [ ] Preview shows column mapping, errors, duplicates.
3. [ ] Approve → background job with progress.
4. [ ] Results CSV attached to the quote with a reason per failed member.
